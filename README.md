# 拼音风火轮 · 围桌版

手机或平板放在桌子中央，大家约定顺时针顺序，口头回答题目后拍首字母卡。React + TypeScript + Vite，纯前端静态网站，无需账号、后端或运行时第三方服务。

## 运行

需要 Node.js 22.12+。

```bash
npm install
npm run dev
npm run build
npm run preview
```

手机与电脑在同一局域网，打开终端显示的 Network 地址。默认开发端口 5173；电脑需保持服务运行。生产文件在 dist/，支持静态部署和子目录部署；尚未发布公网或实现 PWA 离线缓存。

## 本版规则

- 首页快速开始使用默认参数，不覆盖保存过的设置。自定义请进入设置保存并开局。
- 默认隐藏炸弹 30–90 秒、个人倒计时 8 秒、整轮超时上限 3 次。上限可选 1 / 3 / 5 / 不限。
- 个人时间公开显示，题目和倒计时上下双向展示；炸弹准确时间始终隐藏。
- 每次有效选牌立刻换下一位。选中牌立即消失，剩余牌在约 160ms 内重新均匀排列。
- 未达上限时，超时提示这位受罚，立即换下一位继续；卡牌保留，炸弹继续走。需要执行处罚时可手动暂停。
- 达到整轮超时上限才结束；炸弹爆炸或全部卡牌用完也会结束。相同截止时刻炸弹优先。
- 所有字母以单圈弧形牌带围绕中央排列，参考围桌转盘。每次选牌和撤销都重新布局；重排只做快速视觉过渡，不暂停计时、不锁定操作、不显示整理提示。
- 字母沿圆周面向外侧，带底线区分 M / W 等方向；中央题目和个人倒计时仍双向显示。未开放字母不出现。
- 撤销只恢复最近一次选牌，每次选牌最多撤销一次。恢复原个人截止时间、不补时、不取消超时处罚；已发生处罚后恢复旧卡也不会把该处罚重新计算一次。
- 撤销后恢复的字母立即参与单圈重排，不增加额外时间。
- 暂停或切后台冻结两套计时，返回后手动继续。刷新保留已保存的设置，不恢复进行中的游戏。
- 声音从单次低沉心跳渐变为机械敲击，再变成较高音的短脉冲，始终使用单一声源，不叠加高低音轨。节奏前缓后急，约 900ms 到 100ms 一拍。个人末三秒只强调数字和时间环。

## 计时与声光实现

基于 performance.now() 的截止时刻计算，帧循环只读取，不按帧扣秒。延迟帧按真实截止顺序补算超时次数，迟到点击不能替上一位续命。手动暂停或切后台时，统一平移炸弹、个人、撤销记录和提示时间戳。

每轮仅采样一次隐藏炸弹时长。每轮选定略有差异的单调加速曲线，机械音起点随机位于进程 40%–55%，高音阶段 75%–87%，火花与牌环震动共同在高音阶段前约 8% 进程开始，节点在开局确定后不再抖动。各阶段平滑过渡，无假警报或回落。声音、低亮度高斯模糊光雾、牌环震动和由小到大的火花共用一个节拍相位；火花方向与长度按每拍变化，只出现在外围，不阻挡点击。背景每拍仅小幅改变形状与亮度，不再高对比全屏强闪；中央信息不模糊、不震动。个人倒计时独立于炸弹节奏。

## 修改配置

- 题目：编辑 src/game/topics/ 的 topics 数组，新增 id 和 name。类型预留分类、推荐字母与禁用字母。
- 默认参数：编辑 src/utils/storage.ts 的 DEFAULT_SETTINGS。timeoutLimit 为 0 表示不限。旧设置自动补充默认上限 3，其他偏好保留。
- 难度：编辑 src/game/letters.ts，当前简单 13、标准 20、困难 23。

## 验证范围与限制

只运行必要构建与规则快速检查，真机点按由用户验收，见 TESTING.md 和 VALIDATION.md。

未进行浏览器截图、真机音量或触控验收。iOS 无网页震动时自动跳过，音频需开始／继续按钮解锁。设备主线程卡顿时声音和画面可能延迟，计时按截止时刻结算。个人超时处罚和玩家顺序由现场执行，不追踪玩家身份。支持减少动态效果偏好，尚无 PWA、后端或联网多人。

## 多选题库

设置页可同时选择多个题库并展开预览，至少选择一个才能开局。当前 5 组，共 2060 题：轻松上手 12 题；日常联想、开放脑洞、聚会趣味和 🤫🤫🤫 各 512 题。成人题库标注 18+，默认不选；快速开始仅使用轻松上手。

选中的题库合并后按题目等概率抽取，下一轮和重新抽题都限制在已选题库，并排除上一题。不是按游戏进度自动切换风格。设置通过 topicBanks 数组保存。

每个题库独立保存在 src/game/topics/ 下的 1.ts～5.ts，对应轻松上手、日常联想、开放脑洞、聚会趣味、🤫🤫🤫。每个文件使用独立的静态 TypeScript 定义，包含题库 id、name、description 和完全展开的 topics 对象数组；不使用运行时题目生成或公共 helper。四组扩充题库均保留最前面的原有 12 题，新增 500 题的 id 为数字字符串 '13'～'512'。bankId 由题库 id 自动附加，无需逐题填写。

日常联想侧重真实场景与生活经验；开放脑洞允许用短词加解释成立；聚会趣味侧重荒诞、社死和即兴吐槽；🤫🤫🤫 涵盖秘密、消费、职场、身体尴尬和成年人心事，允许虚构答案，不要求自曝。答案由现场玩家判断，通常说一个 2～6 字的词或短语即可。

题库测试检查 5 组、2060 题、连续编号、同组及跨组重名、原有 12 题的内容和顺序，并通过 TypeScript 语法树检查每题均为静态对象。语义近似题通过人工审查修订；格式化、测试和构建分别运行 `npm run format`、`npm test`、`npm run build`。

src/game/topicCatalog.ts 负责汇总题库与抽题；新增题库文件后，在该文件中导入并加入 banks 数组。程序用 bankId + id 区分题目，避免跨题库同号被当成重复题。
